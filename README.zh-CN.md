# Clothesline — Windows 截图晾衣绳

（中文说明。English version below: [README.md](README.md)）

灵感来自 macOS 小工具 [tendedero](https://github.com/alejandrobujan/tendedero)（其代码为 MIT，但名称与图标不在授权内，本项目名称、图标、代码均为原创实现）。每张新截图自动"晾"在屏幕顶部的绳子上：鼠标碰到屏幕顶边绳子滑下来，移开就收回去。

![演示](docs/demo.png)

## 运行

- Windows 10 版本 2004（19041）或更高 / Windows 11，需要 [.NET 10 Desktop Runtime](https://dotnet.microsoft.com/download/dotnet/10.0)（构建需 .NET 10 SDK）。识别文字还要系统里的 OCR 语言包。
- `dotnet build -c Release` 或单文件发布：
  `dotnet publish -c Release -r win-x64 --self-contained false -p:PublishSingleFile=true`
- 不依赖界面的设置 / 夹子列表 / 热键回退，在任意系统上可以跑：
  `dotnet run --project tests/Clothesline.LogicTests.csproj -c Release`
- 窗口、托盘和热键注册需要在 Windows 上构建运行。非 Windows 上直接 `dotnet build` 会报 `NETSDK1100`；交叉编译可加 `-p:EnableWindowsTargeting=true`，产物仍只能在 Windows 上跑。

## 操作

| 操作 | 效果 |
| --- | --- |
| 鼠标在屏幕最顶边停留约半秒 | 晾衣绳滑下。提前移开则不出现。热键和新截图仍然马上显示 |
| 鼠标移开（或点空白绳子） | 收回 |
| 热键（默认 `Ctrl+Alt+T`） | 显示 / 收起。冲突时按 `Ctrl+Alt+L`、`Ctrl+Alt+T` 回退（已经试过的跳过），托盘会提示 |
| 新截图到达 | 绳子"瞄一眼"（滑下约 2.8 秒再收回）。照片在绳子下来的过程中就开始晃 |
| 单击照片 | 复制**原图**到剪贴板，并出现「已复制」小胶囊 |
| 双击 | 用默认看图软件打开 |
| 拖到资源管理器文件夹或桌面 | 从绳子取下，文件保留（系统负责复制或移动） |
| 拖到回收站 | 文件进回收站，并从绳子取下 |
| 拖到聊天 / 编辑器 | 以文件形式拖入，夹子仍留在绳子上 |
| 右键照片 | 打开图片 / 打开所在文件夹 / 贴图 / 识别文字 / 取下 / 取下并删除文件。菜单开着时绳子保持展开，关掉后若鼠标已经离开再收回 |
| 滚轮在照片上 | 放大或缩小这一张。范围是默认 184×216 的 0.5–2 倍 |
| 滚轮在绳子空白处 | 夹子超出屏幕宽度时横向滚动，不显示滚动条。不会同时放大 |
| 托盘图标 | 双击=显示/收起；右键=菜单（热键、剪贴板开关、设置、历史、已打开的贴图、打开文件夹、退出） |

认不出拖拽落点时，绳子不会自己取下。用右键「取下」或「取下并删除文件」即可。删除会把文件移进回收站，可以还原。

## 截图来源

1. **监视文件夹**：默认是 `图片\Screenshots`（`Win+PrintScreen` 的落点，跟随 OneDrive 重定向）。可以在设置里增删多个文件夹。
2. **剪贴板监听**（可关）：`Win+Shift+S` 的结果存成 PNG，放到 `%LOCALAPPDATA%\Clothesline\captures`。可按最小宽高过滤，`0` 表示不限制。

6 秒内同像素内容去重（一次 Win+Shift+S 会同时进剪贴板和自动保存，只挂一张）。

## 设置与重启

托盘菜单「设置…」可改：最多挂件数（默认 20，1–200）、历史条数（默认 50，1–500）、剪贴板开关和最小尺寸、热键、监视文件夹。

这些都写在 `%LOCALAPPDATA%\Clothesline\settings.json`。当前挂着的夹子（路径和角度）写在同目录的 `pegs.json`。重启后还在；文件已经删掉的夹子启动时去掉。`settings.json` 读不出来时程序直接退出，避免用默认值盖掉原文件。`pegs.json` 读不出来时改名为 `pegs.json.bad`，从空绳子继续。

## 贴图、历史、识别文字

- **贴图**不取下夹子。它是单独的置顶玻璃小窗，可以拖动、用右下角的金属角或滚轮缩放。勾选「锁定」后不能再移动或缩放。勾选「穿透」后点击会穿过贴图，并且整窗变为 50% 不透明；要关掉穿透或关掉贴图，用托盘菜单「已打开的贴图」。关掉贴图**不删除文件**，绳子上的夹子还在。
- **取下**（不删除文件）会记入 `%LOCALAPPDATA%\Clothesline\history.json`。托盘「历史…」里可以重新挂上或再贴一张。重新挂上后，这条会从历史里去掉。超过条数时丢掉最旧的。文件已经不在磁盘上的记录，打开历史时丢掉。
- **取下并删除文件**、拖到回收站，不进历史。拖到文件夹时如果原文件还在（一般是复制），会进历史；如果系统把文件挪走了，原路径作废，不进历史。
- **识别文字**用 Windows 自带 OCR，在单独的玻璃窗口里显示结果，**不会**自动复制到剪贴板。拖标题可以移动，拖右下角的金属角可以改大小。可以选中一段再点「复制」；没有选中时「复制」用全文。「翻译」用默认浏览器打开[必应翻译](https://www.bing.com/translator)（`from=auto`，目标 `zh-Hans`）。选中一段就只发送选中内容，否则发送全文；超过 1000 个字符只发送前 1000 个。没有语言包或识别失败时只提示，不退出。单击照片仍然是复制图片，不是贴图。

绳子上的缩略图默认 184×216。滚轮停在某张照片上只缩放那一张；放大时绳子跟着最高的那张变高，缩小不会把绳子降到默认高度以下。滚轮停在空白绳子上只横向滚动。没有 S/M/L 尺寸菜单。

绳子是细的中性灰，有一点高光和软阴影，两端淡出，中间略下垂。夹子是拉丝铝，挂点跟着这道弧走。卡片是半透明玻璃：圆角大约 16，浅色描边，内边距，默认阴影较轻，指针停在卡片上时阴影加深。夹子之间的水平空隙比 184×216 的卡片本身更宽。

本轮没有画笔、箭头、马赛克。

界面文案为中文。

## 已知限制

- 只在主屏展示。绳子按这块屏的工作区宽度铺满顶边；任务栏在左右两侧时不会压到任务栏上。
- 全屏游戏 / 演示模式时新截图不自动弹出（仍会挂上，热键或顶边可唤出）。
- 顶边热区 3px，指针要停约半秒才会拉下绳子；提前移开就取消。若被其他置顶窗口挡住顶边，用热键。热键和新截图不等这半秒。
- 拖到文件夹 / 回收站依赖资源管理器报告落点。第三方文件管理器可能认不出，这时用右键。
- 识别文字依赖 Windows OCR 语言包。翻译走浏览器里的必应翻译，不在应用内翻译。「穿透」打开后贴图是半透明的，只能从托盘关掉。
- 不做长截图拼接，也不做全局 Win+拖拽截图。

## 踩坑记录（给做类似东西的人）

- WPF `Window` 不支持 `RenderTransform`（直接抛异常）；滑动用 `Window.Top` 动画。
- **`Window` 主题默认样式填白底**：删掉 `Background` 属性 ≠ 透明，必须显式 `Background="Transparent"`。
- **分层窗口的鼠标命中按像素 alpha**：全透明窗口被系统整体穿透（`MouseEnter` 永不触发）。需要接鼠标的透明区域刷 **alpha=1**（`#01000000`）。
- **微信等程序复制的 DIB 没有 alpha 字节（全 0）**：直接存 PNG 会整张隐形；按字节抬满 alpha 修复，**不要**用 `FormatConvertedBitmap` 转 `Bgr32`（走预乘空间，A=0 的图会变全黑）。
- 一次 `Clipboard.SetImage` 会触发多次 `WM_CLIPBOARDUPDATE`，必须去重。
